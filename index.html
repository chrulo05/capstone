Smart Load Shedding Controller for Microgrids

Capstone Design Team 5

About Our Project

The goal of this project is to design and build a smart load shedding power system for microgrids. In a microgrid, a small power system is used to supply power to a local area. Under certain conditions, the amount of power being used can exceed the amount provided by the supply. When this happens, the system may become unstable or lose power entirely.

Our system aims to prevent this by intelligently turning off lower priority loads when enough power is not present. Higher priority loads will remain powered as long as possible. Once sufficient power becomes available again, the system will reconnect the lower priority loads, providing them with power again.

This prototype will monitor power production and the usage of each load. The user will be able to select load priority given their specific needs. The system also includes a simple interface so that the user can view the current status of the load shedding system. The primary goals of the project are to produce a fast, reliable, price efficient controller.
